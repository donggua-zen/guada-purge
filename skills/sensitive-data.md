# 敏感数据处理

## 识别

- 凭据：`ghp_`、`github_pat_`、`sk-`、`AKIA`、私钥块、`password=`
- 个人信息：手机号、身份证号、邮箱列表、住址
- 内部地址：内网 IP、数据库连接串、私有域名

## 处理

1. **不复制**：不要把凭据写进代码、日志、提交信息、插件数据目录。
2. **只引用位置**：文档里写"在系统凭据管理器/环境变量 `X` 中"，不写值。
3. **输出脱敏**：展示时保留前 4 位 + 后 4 位，其余替换为 `***`。
4. **最小权限**：token 只申请需要的 scope；用完即删。
5. **轮换**：一旦在对话/日志/仓库中出现过，按泄露处理，立即轮换并更新引用方。
