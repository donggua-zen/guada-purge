# 安全事件初步响应

> 只做**本地、已授权环境**的排查；不要对第三方系统发起扫描或攻击。

## 1. 止损

- [ ] 断开可疑网络连接/停止可疑进程（先记录 PID/命令行）
- [ ] 保留现场：日志、进程列表、最近修改的文件（不要先删除）
- [ ] 轮换可能泄露的凭据（token/密码/密钥）

## 2. 定位

- 最近 24h 的登录/发布/依赖安装记录
- 新增或修改的启动项、计划任务、`postinstall` 脚本
- 异常外联（目标域名/IP、频率、进程）

## 3. 恢复

- 用可信备份恢复被篡改文件
- 重新安装被污染的依赖（核对锁文件与 integrity）
- 复测：最小功能 + 权限边界

## 4. 复盘

输出时间线、根因、影响面、改进项；敏感值一律脱敏。
