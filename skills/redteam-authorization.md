# 演练授权检查

在开始任何演练前，确认以下全部为"是"：

- [ ] 目标是**本机环境**、离线靶标，或已取得**书面授权**的系统
- [ ] 授权范围写明：域名/IP、时间窗、允许的技术、禁止的动作
- [ ] 已约定应急联系人、停止信号、数据处置方式
- [ ] 不涉及生产数据、不持久化驻留、不横向移动到授权范围外
- [ ] 不针对关键基础设施、金融、政务、医疗等敏感行业（除非另有合规授权）

禁止：

- 对未授权目标扫描、探测、投递 payload
- 使用真实凭据以外的凭据进行登录尝试
- 破坏数据、加密勒索、批量外传

输出：授权范围摘要 + 检查结果；任一项为"否"时停止并说明缺口。
