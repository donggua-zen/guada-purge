# 规则集编写

一个规则文件由 frontmatter + 正文组成：

```md
---
name: 前端规范
paths: frontend/**, packages/web/**
---
正文……
```

要求：

1. `name` 用一句话说明适用面；`paths` 用逗号分隔，留空表示全局生效。
2. 每条规则写成**可验证的行为**：
   - 好：提交前运行 `pnpm test`。
   - 差：保证代码质量。
3. 单条规则不超过两行；超过时拆成子项。
4. 不写与工具能力冲突的规则（例如要求"自动部署"但项目没有部署脚本）。
5. 规则之间不要互相引用编号（重排后会失效）。

输出：直接给出完整文件内容，并在末尾列出"适用路径/验证方式"。
