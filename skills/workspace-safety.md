# 工作区安全清单

在执行以下操作前，逐项确认：

- [ ] **删除/覆盖**：目标是否在版本控制内？是否有备份或可重建？
- [ ] **批量修改**：先用 `git status` / 文件清单确认范围；避免通配符误伤。
- [ ] **依赖安装**：是否会改动锁文件？是否引入 postinstall 脚本？
- [ ] **权限提升**：是否真的需要更高沙箱档位？能否用只读方式完成？
- [ ] **外部网络**：是否会向第三方上传代码/数据？是否有脱敏？
- [ ] **回滚**：失败时如何恢复？记录本次改动的文件列表。

任一项无法确认时，先向用户说明风险并等待确认，不要"先做再补"。
