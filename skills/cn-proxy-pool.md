# 出口代理池

> **可选能力**：需要你自备代理资源（购买的住宅/机房代理，或自建多台 VPS）。
> 没有资源就别用本技能，直接降速即可。

## 什么时候需要

- 目标有 IP 级封禁（扫几十个请求就 403）
- 需要从不同地域探测（CDN 回源判定）
- 大规模目录爆破想让流量分散

**不需要时别用**：代理链会拖慢速度，也会引入不稳定因素。

## 组织方式

| 方案 | 适用 | 成本 |
|---|---|---|
| 自建多 VPS + ssh -D | 完全可控 | 中 |
| 商业住宅代理 | 抗封强 | 高 |
| 云函数轮换出口 | 轻量、弹性 | 低 |

## 使用方式

```bash
# 单个 socks5
curl --socks5-hostname 127.0.0.1:1080 https://target

# 列表轮换
for p in $(cat proxies.txt); do
  curl --socks5-hostname "$p" -m 5 https://target -o /dev/null -w "$p %{http_code}\n"
done
```

ffuf 等工具支持 `-x` 指定代理文件。

## 落库

代理本身不进资产库。若某条代理出口 IP 被用于踩点，把"出口 IP"记进链步骤的 `detail`（排查时有用）。

## 判定标准

- [ ] 代理可用性已批量验证（不通的先剔除）
- [ ] 限速仍然要设（代理不等于可以狂扫）
- [ ] 授权范围允许从其他地域访问

## 常见坑

| 坑 | 处理 |
|---|---|
| 代理失效率高 | 先跑一遍可用性检查 |
| 用了来路不明的免费代理 | 流量会被中间人看，**禁止**用于带凭据的请求 |
| 忘了仍然要限速 | 代理只是换 IP，不解决打挂问题 |
