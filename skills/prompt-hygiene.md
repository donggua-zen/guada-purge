# 提示词卫生检查

按顺序检查当前提示词：

1. **重复**：同一约束是否出现两次以上？合并为一条。
2. **冲突**：是否同时要求"简洁"和"详尽"、"只读"和"直接修改"？保留优先级更高的一条，删除另一条。
3. **过期**：是否引用了已删除的文件、旧接口、旧版本号？用当前工作区核对后删除。
4. **可执行性**：每条约束是否能被验证（例如"必须运行测试"优于"注意质量"）？
5. **作用域**：项目级规范放规则集，个人偏好放人格文本，不要混在一起。

输出：按「问题 → 建议改法 → 影响的段落」三列给出；没有问题时明确说"未发现"。
